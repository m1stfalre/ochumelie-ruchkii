# CI/CD Pipeline Documentation

## Обзор

Пайплайн автоматизирует тестирование, проверку качества кода и симуляцию деплоя.

## Триггеры

- Push или Pull Request в ветки: `dev`, `qa`, `master`/`main`

## Шаги пайплайна

### 1. Тестирование (test-and-analyze)

- PHPUnit с проверкой покрытия кода
- **Условие провала:** покрытие < 70% или любой упавший тест
- Использует `.env.ci` с SQLite in-memory

### 2. Статический анализ

- Larastan (PHPStan для Laravel)
- **Условие провала:** любая ошибка PHPStan

### 3. Линтинг

- Laravel Pint с пресетом PSR-12
- **Условие провала:** любое нарушение стиля кода

### 4. Симуляция деплоя

- Запускается только после успешных предыдущих шагов
- Копирует соответствующий .env файл:
    - `dev` → `.env.dev`
    - `qa` → `.env.uat`
    - `master`/`main` → `.env.prod`

## Локальный запуск

```bash
# Запуск тестов
php artisan test

# Статический анализ
vendor/bin/phpstan analyse app/

# Линтинг
vendor/bin/pint --test
```
